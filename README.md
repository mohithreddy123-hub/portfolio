# Karnati Mohith Reddy — Portfolio

A premium, interactive personal portfolio showcasing my software engineering journey, specialized skills, and featured projects. Built with a focus on immersive UI/UX, fluid animations, and high performance.

## 🚀 Tech Stack

- **Frontend:** React.js, JavaScript (ES6+)
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Scrolling:** Lenis Smooth Scroll
- **Icons:** Lucide React

## ✨ Key Features

- **Modern Visual Design:** Sleek dark-mode aesthetic with interactive glassmorphism components.
- **Fluid Motion:** Micro-interactions, custom magnetic cursor effects, and smooth page scroll.
- **Dynamic Projects Showcase:** Interactive project viewer featuring integrated screen size/device simulators.
- **Interactive Skills Deck:** Hover-triggered tech stack inspector showing contextual descriptions of each technology.
- **Particle Dynamics:** Live background simulation using HTML5 canvas particles.

## 🛠️ Local Development

Clone the repository and install the dependencies to run the project locally:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
